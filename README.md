## 🧭 About Me

I'm a Computer Engineer from Damascus building full-stack web apps, cross-platform mobile apps, and AI-powered tools — from marketplace platforms to assistive vision systems for the visually impaired. I care about clean architecture, real-time data, and shipping products people actually use.

- 🔭 Currently building **Luqta**, a mobile marketplace for buying/selling devices in Syria
- 🌱 Exploring **AI/edge inference** (YOLOv8, ONNX) for assistive technology
- 🛠️ Comfortable across the stack: Flutter/React on the front, Node/NestJS/FastAPI on the back
- 🤝 Open to collaboration on mobile, AI, and civic/education tech projects
- ⚡ Fun fact: I build with AI-assisted workflows (Claude Code, Cursor) to move fast without cutting corners
